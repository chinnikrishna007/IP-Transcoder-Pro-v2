Every input, one core, every output.

**IP Transcoder Pro v2** is an enterprise-grade live IPTV and OTT encoding engine. It ingests live signals over RTMP, SRT, UDP, and HLS, then seamlessly re-encodes and repackages them into the delivery formats your platform requires—without the need to manage a rack of separate tools.

---

## 🚀 Core Features

* **Multi-Protocol Ingest:** Pull or receive live signals over RTMP/S, SRT, RTSP, UDP/RTP, and HLS side by side from a single instance.
* **Format-Flexible Output:** Repackage the same source feed into HLS (with DRM support), MPEG-DASH, RTMP push, and UDP/RTP multicast for various delivery targets including set-top boxes, browsers, and mobile apps.
* **Hardware-Accelerated Encoding:** Offload encoding tasks to supported GPU hardware, maximizing the number of channels you can run per server.
* **Adaptive Bitrate (ABR) Ladders:** Define custom bitrate and resolution ladders per channel to ensure smooth playback across fluctuating viewer connections.
* **Channel & Program Management:** Group inputs and outputs into named channels, schedule dynamic changes, and monitor per-channel signal health with instant drop/stall alerts.

## ⚙️ Installation & Setup

1. Download the latest installer for Windows 10 or 11 from the [Official Download Page](https://www.iptranscoderpro.com/IPTranscoder_Pro_v2_Setup.exe) page.
2. Run the executable (`IPTranscoder_Pro_v2_Setup.exe`) and follow the on-screen prompts.
3. Launch the IP Transcoder Pro console.
4. Configure your input ingest streams and map them to your desired output formats and delivery targets.
